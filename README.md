# 💰 Ahorro Pro

Una aplicación web para ahorrar dinero de forma sencilla y visual.

---

# 🎯 Objetivos

- Ahorrar dinero para cualquier proyecto.
- Ver el progreso mediante una barra.
- Personalizar el nombre, emoji y objetivos.
- Guardar el progreso automáticamente.
